### Novissium

Independent software, icons and design tools from Switzerland.

**Icons**
- [IconSouk](https://iconsouk.com): 58,000+ free SVG icons in 33 sets, with SVG, React, Vue and CSS export

**WordPress**
- [NoviDeck](https://wordpress.org/plugins/novideck/): sell your Freemius products from Elementor
- [NoviFix](https://github.com/Novissium/NoviFix): global color variables in Elementor background gradients
